## 🏢 Sobre nosotros

**Urci Consultores** es una consultora de ingeniería que automatiza su trabajo diario con software a medida. Nuestros repositorios reúnen sistemas web, aplicaciones de escritorio, plugins para CAD y utilitarios que reducen tiempos y errores en proyectos de campo y gabinete.

## 🧩 Nuestros proyectos

### 🗺️ PACRI 360 — Gestión catastral y registral de predios

| Repositorio | Descripción | Tecnología |
|---|---|---|
| [`pacri_backend`](https://github.com/UrciConsultores/pacri_backend) | API del sistema PACRI 360: JWT + Azure AD, importación/exportación geoespacial (GDAL), generación de PDF y Excel. Contenerizada y desplegada en Kubernetes. | C# · .NET 8 · PostgreSQL |
| [`pacri_frontend`](https://github.com/UrciConsultores/pacri_frontend) | Aplicación web para la gestión integral de proyectos, maestros, personal y brigadas. | Angular 19 · PrimeNG · TailwindCSS |
| [`pacri_desktop`](https://github.com/UrciConsultores/pacri_desktop) | Aplicación de escritorio para reportes (CBC, Diagnóstico Técnico Legal, Expedientes) con generación de documentos Word desde plantillas. | C# · WinForms · .NET 8 |

### 🌿 Ambiental y documental

| Repositorio | Descripción | Tecnología |
|---|---|---|
| [`UrciEIA`](https://github.com/UrciConsultores/UrciEIA) | Matriz de identificación de impactos ambientales: cruza actividades del proyecto con factores ambientales, evalúa la importancia del impacto y mantiene trazabilidad. | C# · PostgreSQL · Docker/K8s |
| [`UrciCorrespondencia`](https://github.com/UrciConsultores/UrciCorrespondencia) | Mesa de partes interna y externa: correlativos automáticos, trazabilidad de redirecciones, RBAC e integración con el sistema legado. | .NET 8 · Angular 21 · PostgreSQL |

### 📐 Topografía, CAD y laboratorio

| Repositorio | Descripción | Tecnología |
|---|---|---|
| [`ZWCadCommands`](https://github.com/UrciConsultores/ZWCadCommands) | Plugins para ZWCAD: coordenadas, áreas, láminas, metrados por secciones y ejes, impresión PDF masiva, bloques ↔ Excel y progresivas de drenaje. | C# · .NET Framework 4.7.2 |

## 🛠️ Stack y prácticas

- **Backend:** .NET 8 (Web API), Entity Framework Core, PostgreSQL
- **Frontend:** Angular, PrimeNG, TypeScript
- **Escritorio y CAD:** WinForms, plugins .NET para ZWCAD
- **Datos y automatización:** Python, VBA, Excel, GDAL
- **Infraestructura:** Docker, Kubernetes, GitHub Actions (CI/CD)
